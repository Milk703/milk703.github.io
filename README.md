## Đưa lên HTTPS
GitHub Pages có thể biến repository thành website live và user site mặc định có dạng `https://nhattuan.github.io`.

1. Tạo repository công khai tên `nhattuan.github.io`.
2. Upload toàn bộ nội dung thư mục này.
3. GitHub → Settings → Pages → Source: Deploy from a branch → chọn `main` và `/root`.
4. Mở `https://nhattuan.github.io/`.

Bạn cũng có thể mua domain riêng rồi trỏ vào GitHub Pages.
